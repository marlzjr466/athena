# Optional voice-tool workflow

Use this only when the current agent exposes an authorized voice/audio tool.

## Procedure

1. Discover available voice tools and read their schemas.
2. Confirm supported language, voice options, output format, limits, and price.
3. Ask for missing requirements only when they affect the output.
4. Tell the user about a separate charge before a billable call when required.
5. Obtain any required confirmation.
6. Call the exact available tool with validated parameters.
7. Inspect the returned result and provide the artifact or verified link.

## Do not

- Assume a provider is connected because its name appears in this document.
- Ask the user to paste API keys into chat.
- Claim a file was generated if the tool did not return it.
- Claim unlimited usage or bundled credits without verified terms.
- Clone a real person's voice without authorization.

## If no tool is available

Say that voice generation is not available in the current session. Offer to prepare narration text, pronunciation notes, or a provider-ready prompt instead.
