# Capability boundaries

## What the skill provides

- Structured software engineering workflows
- Repository inspection and implementation guidance
- Debugging and code review checklists
- Architecture and technical decision support
- Documentation and delivery templates
- Model/tool selection guidance based on capabilities actually exposed
- Voice-generation workflow guidance when an authorized tool is available

## What it does not provide by itself

- Athena's Electron desktop app, UI, or 3D avatar
- A hosted backend, MCP server, or API
- Local model binaries or inference runtime
- Access to private repositories or local files without agent permissions
- Provider accounts, API credentials, or subscription entitlements
- Guaranteed access to ElevenLabs, MiniMax, HeyGen, or other tools
- Included or unlimited third-party tool usage

## Important commercial distinction

The Agensi skill purchase pays for access to this instruction package. Third-party Agensi tools may have separate usage charges and approval flows. Never describe third-party tool calls as included in the skill price unless the listing explicitly says so and the platform confirms it.

## Required honesty

The agent must distinguish:
- available vs. unavailable tools
- inspected vs. uninspected files
- proposed vs. completed changes
- attempted vs. successful commands
- generated vs. merely drafted audio
- mock API behavior vs. live backend behavior
