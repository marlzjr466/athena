# Floating Athena voice

Local Whisper recognizes the wake phrase. Only an explicit cloud voice opt-in and a wake or Settings test may open a GPT-Live session. The Electron main process owns API authorization, a single session lease, deadlines and durable budget reservations. The owning renderer supplies SDP and routes one remote track to the selected speaker. Previously selected local synthesis remains the fallback.

A session uses client delegation. Only user transcript fragments associated with a delegation enter the existing hands-free action path. Existing project, submission and action approvals apply. Preview sessions have no automation. Conversation history and recorded audio are excluded from startup.

Implement and verify the typed settings and provider contracts, the metered main-process session lifecycle, the floating peer and delegation bridge, then the designer and preview controls. Acceptance requires exclusive ownership, no network microphone before wake, bounded idle and total duration, duplicate-event protection, private output routing, and teardown on loss of permission or ownership. Durable usage is an Athena estimate. Custom voice creation is explicit, and a saved identifier survives restarts.

Contracts: [Live](https://developers.openai.com/api/docs/guides/live), [client delegation](https://developers.openai.com/api/docs/guides/live-delegation), [custom voices](https://developers.openai.com/api/docs/guides/custom-voices), [duration pricing](https://developers.openai.com/api/docs/pricing#live-session-duration).
