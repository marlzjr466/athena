# Athena Academy local adapter training

Athena uses a dedicated Python 3.11 environment at `~/.athena/models/training/runtime`. On this Mac it contains `mlx-lm[train]` 0.32.0, MLX 0.32.4, Hugging Face Hub, and `datasets`. A Metal device was detected outside the development tool sandbox on 2026-10-19. Athena's voice Python environment was not changed. If the dedicated runtime is missing on a future installation, Academy offers an explicit **Set up local training runtime** action with confirmation and cancellation; it does not silently install packages.

Ollama's quantized inference blobs are **not** training checkpoints. Athena uses a separate, validated MLX-compatible source checkpoint for LoRA/QLoRA. A Qwen2.5-Coder-3B-Instruct source checkpoint and completed 100-iteration adapter job are now present in this installation; this document does not authorize retraining or deployment.

In My Athena → Athena Academy → LoRA / QLoRA fine-tuning, select the installed model. The suggested repositories are `Qwen/Qwen2.5-3B-Instruct` and `Qwen/Qwen2.5-Coder-3B-Instruct`, respectively. These are plausible source candidates based on their tags, **not verified provenance matches** for the Ollama artifacts. Review each model card and license, then explicitly choose **Download source checkpoint** or a local MLX-compatible checkpoint directory. Athena validates the architecture, tokenizer and safetensors. It will not execute remote model code or accept the Ollama blobs as weights.

Import a JSONL dataset with 10–20,000 `text` or `messages` records. Athena copies it into private application data and deterministically splits it into train, validation and held-out test sets. No training data is sent to a cloud AI provider. Checkpoint downloads are bounded to 12 GiB of reported safetensors and require sufficient free disk; unknown-size sources are refused. Public downloads do not reuse stored Hugging Face credentials. After explicit confirmation, training uses a bounded 50–500 iterations, batch size 1, sequence length 1024, eight adapted layers, gradient checkpointing and saved adapter checkpoints. A quantized MLX checkpoint enables QLoRA; a full-precision one uses LoRA. Full-precision sources above 8 GiB are refused on this 24 GB preset. Training can be cancelled and resumed from a saved adapter. A held-out MLX loss evaluation and checkpoint selection are available.

Use **Compare base + all checkpoints** to evaluate the unadapted source and every saved adapter sequentially. All variants use the same source tokenizer, 1,024-token loss window, full private validation and test splits, batch size 1, and (if imported) the same independent labeled prompts with deterministic greedy generation capped at 96 tokens. The comparison does not retrain, select, or deploy any checkpoint. It records separate validation/test losses, AI Coding/Git/Jira exact-answer match rates with 95% Wilson intervals, and actual base/adapter answers side by side. Exact matching is a narrow automated check, not a semantic or executable-code judgment.

An optional independent JSONL evaluation file can contain 1–200 records (4 MB maximum), for example `{"track":"coding","prompt":"...","expected":"..."}`. `track` is `coding`, `git`, or `jira`; `expected` may also be an array of acceptable answers. Keep this file separate from training and make it large and diverse enough to support the three categories—30 or more examples per category is recommended. Athena preserves the imported training dataset and existing adapters. A tiny held-out split, wide correctness intervals, or a validation-to-test loss gap is flagged as uncertain/possible overfitting. A checkpoint recommendation is for review only and never auto-deploys.

On the existing 4-example held-out split, the real MLX comparison measured base validation/test losses of 4.558/4.867 and the five saved checkpoint test losses of 2.627 (25), 2.291 (50), 2.275 (75), 2.360 (100), and 2.360 (final adapter). The 75-iteration checkpoint is the provisional loss-only leader. The earlier recorded 1.476 validation loss came from training-time sampled validation batches; the new full-split metric for the 100-iteration adapter is 1.927, so they are not directly interchangeable. No independent labeled AI Coding/Git/Jira set has yet been imported, so task-level correctness remains unmeasured.

Adapter selection/rollback in Academy changes which **saved adapter file** is designated. It does not replace the Ollama model. Current Ollama does not load MLX adapters directly, so Athena does not claim that the floating companion or local chat has learned the new weights. A separate, validated model-conversion/import path is needed before deployment. Knowledge indexing, skills and approved correction examples remain independent of model-weight training and available when MLX compatibility is absent.

The new Electron main handler requires an app restart to become active in an already-running application; frontend HMR alone cannot load it. No app, dev server, or production build was restarted for this comparison implementation.
